## 확인하지 않은 것

한국어 의미 동치, 기술적 사실의 참·거짓, 가상 라벨의 사람 합의, 독자의 이해도, 실제 linter 탐지율, 호스트별 설치·로드, 외부 전송 통제의 강제성, 여러 OS/Python 버전 호환성, 상표·특허 등록 가능성은 검증하지 않았다.

24개 단위테스트는 **구조 검사 도구의 테스트**다. 48건의 문장을 의미 평가 엔진에 넣어 모두 맞혔다는 의미가 아니다. 가상 자료의 라벨은 AI 작성 초안 상태다.

이번 자료 조사는 지정한 원문과 범위를 확인한 문헌 검토다. 연구의 모델 학습·실험 재현·사람 대상 실험을 실행하지 않았다. 실제 GitHub 저장소에는 파일 추가·커밋·push·PR·릴리스를 수행하지 않았다.

## 검사 도구의 알려진 한계

`validate_package.py`의 Markdown 검사는 패키지에서 사용하는 단순 인라인 링크의 파일 존재 여부만 확인한다. 외부 URL의 생존 여부, 제목 앵커, 전체 CommonMark, 임의 YAML/CFF의 모든 스키마를 검증하지 않는다. SKILL 메타데이터 검사는 알려진 필드의 제한적 확인이다.

`render_rules.py`는 JSON에 적힌 규칙을 표로 옮길 뿐 규칙의 타당성을 판정하지 않는다. 정본 자체가 잘못되면 잘못된 표를 정확하게 생성할 수 있다.
