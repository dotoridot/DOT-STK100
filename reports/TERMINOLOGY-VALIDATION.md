# 기술적 용어 구분 개선의 검증 기록

확인 날짜: 2026-11-09. 이 기록의 58개 테스트와 예시 대조는 초기 PR 커밋 6c99fbf 기준이다. 권장 표현 선택을 보완한 최신 검사는 [후속 검증 기록](EXPRESSION-VALIDATION.md)을 따른다. 현재 배포 버전 0.0.2에 대한 미출시 개선이다.

## 실행 범위

기존 12개 용어 쌍과 정의를 유지하고 4개 쌍을 추가했다. 규칙 수 32개와 ID를 유지하며 K05에 용어 항목의 검토 정보를 보완했다. 모든 16개 항목은 정의, 규칙 ID, 세 종류의 예시와 예외를 포함한다.

새 테스트를 수정 전 구현에서 실행해 사전 검증 계약과 용어 ID 경고가 없어 실패함을 확인했다. 개발 예시 집계 옵션도 구현 전에는 미지원 인자로 실패했다. 구현 후 생성 규칙표 검사, 패키지 검사, 스킬 구조 검사와 unittest 58개가 통과했다. 이 검사는 정의의 형식과 규칙 참조, 보고 전용 동작과 경고 추적 계약을 확인한다. 의미 보존 효과를 검증하는 검사는 아니다.

## 개발 예시 경고 집계

```bash
python3 scripts/evaluate_linter.py --terminology-examples
```

용어집 예시 48건은 16개 계열의 공개 합성 개발 자료다. AI 초안 기대 라벨이므로 독립 평가 정답이 아니다. 문서 하나에서 관련 여부와 무관하게 아무 경고가 발생했는지를 센 결과는 다음과 같다.

| 항목 | 건수 |
|---|---|
| 의미 변경 초안 라벨에서 경고 있음 | 15 |
| 의미 변경 초안 라벨에서 경고 없음 | 1 |
| 보존 초안 라벨에서 경고 있음 | 3 |
| 보존 초안 라벨에서 경고 없음 | 13 |
| 문맥 부족으로 이진 집계 제외 | 16 |

위 표는 사람 기준 오탐과 미탐, 스킬의 의미 보존 정확도가 아니다. 경고의 관련성도 사람이 주석하지 않았다. 경고 없음 1건과 보존 초안 라벨의 경고 3건을 합격으로 숨기지 않는다. 사람 precision과 recall은 null로 남긴다.

기본 seed 56건도 별도로 실행했다. 같은 기준으로 경고 있음/없음은 의미 변경 초안 20/6건, 보존 초안 11/15건이며 문맥 부족 4건은 제외했다. 이 자료를 용어집 예시와 합쳐 독립 표본이나 성능 향상으로 보고하지 않는다.

## 스킬 예시와 독립 효과 평가

[가상 입력](../eval/terminology-prompts.json)의 지원 범위, 비교 경계, 프로젝트 UI 예외를 개선 전과 후의 별도 에이전트 문맥에서 실행했다. 실행 결과를 변형 이름을 가린 독립 검토에 제공했다. 이 소규모 실행은 회귀 후보 확인이며 실제 호스트의 모델 호출이나 독립 사람 효과 평가를 대체하지 않는다. 실험 조건과 검토 절차는 [평가 계획](../docs/EVALUATION.md)에 따른다.

의미 보존 효과, 독자 이해도와 사람 기준 경고 정확도는 아직 검증하지 않았다. 용어 사전 확장이나 구조 검사 통과를 AI 오류 감소의 증거로 사용하지 않는다.

## 소규모 출력 대조의 관찰

지원과 호환, 권장과 필수의 rewrite에서는 두 변형 모두 주어진 근거 범위와 의무 수준을 유지했다. 경계값과 실행 상태 review에서도 두 변형 모두 의미 차이를 설명했다. 코드와 UI 예외 rewrite에서는 두 변형 모두 인용과 미수행 상태를 보존했지만 개선 전 출력은 편집 지시를 수신자에게 요구하는 문장으로 추가했다.

사전 예외를 입력 판단에 필요할 때만 설명하고 새 사실이나 행동 의무로 옮기지 않는 기준을 보완한 뒤 경계와 실행 상태 사례를 다시 실행했다. 두 의미 차이와 원문 표현 유지 제안을 확인했으며, 독립 출력 재검토에서도 정의와 review 출력 계약에 부합함을 확인했다.

가린 출력 검토 자료에는 스킬이 실제 읽은 참조 일부가 생략되어 있었다. 이 때문에 처음 제기된 정의 자료와 조건부 예외 제안의 근거 범위 의문은 참조를 보완한 뒤 판단을 갱신했다. 자료의 합성 여부에 관한 출력은 실제 용어집의 origin, split과 label_status를 대조했다. 독립 사람 주석, 반복 실험, 잠금 자료와 효과 추정은 수행하지 않았다. 이 결과는 우열이나 오류 감소율을 입증하지 않는다.
