# 권장 표현 선택 보완의 검증 기록

확인 날짜: 2026-11-09. PR #3의 초기 용어 구분 개선 이후에 추가한 미출시 보완이다. 배포 버전은 0.0.2로 유지한다.

## 변경 범위

8개 권장 표현 항목에 뜻, 적용 조건, 예외, 관련 규칙 ID와 세 종류의 합성 개발 예시 24개를 추가했다. K07과 스킬 공통 진입점에서 같은 의미의 익숙한 표현과 직접적인 동사를 선택하도록 명시했다. 전문 용어, 인용, 부정, 조건과 의무는 보존한다.

Linter는 일부 고정 문자열 신호를 찾고 기존 terminology check의 YSK-K07/EXPR 경고 후보로 보고한다. 자동 치환값을 반환하거나 파일을 고치지 않는다. 표현 사전 해시를 기록하기 위해 출력 schema_version을 0.2, tool_version을 0.2.0으로 변경했다. 기존 스키마를 고정해 쓰는 소비자는 새 스키마를 적용해야 한다.

## 검사

새 테스트를 수정 전 구현에서 실행해 사전 검증 함수와 권장 표현 경고가 없어 실패하는 것을 확인했다. 집계 결과에 권장 표현 설정 해시가 없는 상태의 실패도 별도로 확인했다. 구현 후 생성 표 검사, 패키지 검사, 스킬 구조 검사와 unittest 66개가 통과했다.

새 8개 테스트는 사전의 적용 조건과 예외 및 예시 형식, 신호 중복과 잘못된 규칙 참조, 후보 경고의 ID와 위치, 보호 구간, 직접적인 표현의 비경고, 부정 및 모호한 의무 표현의 비자동수정, CLI 입력 바이트 보존, 집계 설정 해시를 확인한다. 이 테스트는 어휘 선택이 실제 독자의 이해도나 의미 보존을 개선했다는 근거가 아니다.

기본 seed 56건과 용어 예시 48건도 다시 실행했다. 문서 하나의 any-warning 기준 집계는 초기 PR과 같았다. 이 수치는 문체 후보가 포함될 수 있는 개발용 지표이며 의미 판정 정확도가 아니다. 사람 precision과 recall은 null이다.

## 가상 작업의 전후 대조

[입력 자료](../eval/expression-prompts.json)의 세 작업을 초기 PR 스킬과 보완 스킬의 별도 에이전트 문맥에서 각각 실행했다. 일반적인 작업 안내, 고유한 진단 절차 이름과 시작 범위, 의무 및 실제 동작 근거가 불명확한 문장을 다룬다. 결과는 변형 이름을 가린 독립 문장 대조로 확인했다.

일반 작업 안내에서는 두 변형이 같은 직접적인 동사 문장을 생성했다. 이는 일반 서술 규칙만으로도 해당 입력을 편집할 수 있었음을 보여주며 새 사전의 효과 차이를 입증하지 않는다. 진단 절차 사례에서는 초기 PR 출력이 일반 검사와 같은지 미정이라는 문장을 생략했지만, 보완 출력은 해당 정보와 절차 이름, 시작 범위를 유지했다. 모호한 의무와 실제 동작 근거 사례에서는 양쪽 모두 범위를 유지했다. 세 사례만으로 일반적인 효과 차이를 판단하지 않는다.

정확한 모델 식별자와 샘플링 설정은 이 런타임에서 확인하지 못했다. 각 작업을 한 번씩 실행한 공개 개발 예시이므로 효과 크기, 일반적인 우열과 오류 감소율은 추정하지 않는다. 독립 사람 평가, 잠금 자료와 실제 Codex/Claude 호스트 호출은 미실행이다.
