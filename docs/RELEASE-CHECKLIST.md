# 공개 반영 체크리스트

기록 대상: `0.2.0-draft.3` 준비 작업 · 기록 상태: **과거 공개 준비 기록**

현재 공개 버전은 `0.0.2`다. 아래 체크 항목은 당시 `0.2.0-draft.3` 준비 과정의 확인 기록이며, 현재 버전의 공개 상태나 모든 항목의 최신 완료를 뜻하지 않는다. 최신 배포 버전과 검사 상태는 [README](../README.md), [변경 이력](../CHANGELOG.md), [검사 보고서](../reports/VALIDATION.md)에서 확인한다. 미체크 항목은 실제 확인 전까지 그대로 둔다.

## 1. 표시와 권리

- [x] 이번 사용자 지시의 프로젝트 표시명 DOT-STK100과 저작자 dotoridot을 반영했다. 공개 승인은 별도다.
- [x] 100이 규칙 수·점수·완성도라는 오해를 막는 문장이 있다.
- [x] ASD·STEMG의 공식 한국어판·공인·인증·추천을 주장하지 않는다.
- [ ] 명칭 충돌 확인의 범위를 기록했다. 검색 결과 부재를 법적 사용 보장으로 쓰지 않는다.
- [x] 사용자가 프로젝트 전체 MIT 적용을 선택했고 LICENSE에 반영했다.
- [x] LICENSE.md와 SKILL/CITATION의 라이선스를 MIT로 맞췄다.
- [x] AUTHORS·CITATION에 허위 이름·DOI·저장소 주소·출시일이 없다.
- [x] 논문·표준·공공 자료 원문을 허가 없이 재배포하지 않는다.

## 2. 내용과 데이터

- [x] 규칙과 SKILL의 작업 범위가 일치한다.
- [x] 원문 충실성과 사실 검증이 분리돼 있다.
- [x] 가상 사례의 라벨을 사람이 검토했는지, 하지 않았는지 명시했다.
- [ ] 사례에 실제 사내 코드·로그·사용자 대화·개인정보가 없다.
- [ ] 패키지 전체와 추가한 Git 이력에 비밀이 없는지 확인했다.
- [x] 참고 연구의 언어·도메인·검토 범위·한계를 표시했다.

## 3. 검증과 주장

- [x] 규칙 표 동기화·파일 참조·구조 테스트를 실제 실행했다. 실행 기록: reports/VALIDATION.md.
- [x] 구조 검사 통과를 의미·사실 검증 완료로 쓰지 않는다.
- [x] 호스트 테스트·모델 실행·사람 실험의 실행/미실행을 구분한다.
- [x] 효과 검증 전 상태를 README에 유지한다.
- [x] 초안이 아닌 v1.0 또는 인증 배지를 임의로 붙이지 않는다.

## 4. 저장소와 배포

- [x] dotoridot 소유 DOT-STK100 공개 저장소 생성과 업로드를 사용자가 승인했다.
- [ ] 기존 변경을 보존하고 파일 충돌을 검토했다.
- [x] 기존 korean-humanizer 계약을 별도 승인 없이 바꾸지 않았다.
- [x] 기존 저장소 참조 수정과 새 저장소 생성/업로드 승인을 확인했다. 태그/릴리스는 범위에 포함하지 않는다.
- [ ] 승인 후 실제 URL·커밋·태그만 문서에 추가했다.
- [x] ZIP 압축 해제 후 구조 검사·단위테스트와 상대 파일 경로 검사를 완료했다. 호스트 설치 테스트는 미실행이다.

체크리스트에 체크하는 주체는 실제 확인자다. 이 파일을 생성한 것만으로 체크하지 않는다.
